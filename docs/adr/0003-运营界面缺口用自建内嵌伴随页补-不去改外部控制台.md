# ADR 0003 — 运营界面缺口用自建内嵌伴随页补，不去改外部控制台

**Status:** accepted

`management.html` 是从外部仓库 `router-for-me/Cli-Proxy-API-Management-Center` 的 Release 拉取、每约 3 小时按 SHA256 自动覆盖的资产 —— 本地改动会被冲掉，也进不了它的发布流程。因此当需要一个外部面板没有的运营控件时，不 fork、不注入外部 HTML，而是在本二进制里 `go:embed` 一个自己的页面、挂到自有路由（如 `/usage-mode.html`）。

约定：HTML 本身不鉴权返回（照 `management.html` 的服务方式，在 `disable-control-panel` group 之外），页面 JS 用同一个管理密钥（`SecretKey`/`MANAGEMENT_PASSWORD`/本地密码，`Authorization: Bearer`）调 `/v0/management/*`；用 `RemoteManagement.DisableControlPanel` 同步门控（面板关则伴随页也 404）。这样外部资产照常自动更新、我们零 fork，缺口能力完全自持、可增量追加下一个控件。
